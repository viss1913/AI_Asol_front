# 🚀 Инструкция по деплою на Яндекс.Облако

Для деплоя фронтенда AI Asol Studio на Яндекс.Облако (через Object Storage) выполните следующие шаги:

## 1. Сборка проекта
В корневой директории проекта выполните команду:
```powershell
npm run build
```
После завершения появится папка `dist/`. Это и есть готовое приложение, которое нужно загрузить в облако.

## 2. Подготовка Яндекс Object Storage
1. Зайдите в [Консоль Яндекс Облака](https://console.cloud.yandex.ru/).
2. Создайте новый **Бакет** (Bucket). Назовите его, например, `ai-asol-front`.
    - Доступ: Публичный (для статического сайта).
3. Перейдите в раздел **Веб-сайт** в настройках бакета.
    - Выберите "Хостинг".
    - Главная страница: `index.html`.
    - Страница ошибки: `index.html` (важно для Single Page Application, чтобы роутинг работал корректно).

## 3. Загрузка файлов
Загрузите всё содержимое папки `dist/` в корень вашего бакета.
> [!TIP]
> Лучше всего использовать утилиту `rclone` или `aws cli` (настроив эндпоинт Яндекса), чтобы загружать папки целиком автоматически.

## 4. Настройка Домена (опционально)
В настройках бакета (раздел "Домены") вы можете привязать свой домен, создав CNAME запись в DNS.

## 5. Проверка SEO
После деплоя:
- Проверьте наличие `robots.txt` и `sitemap.xml` в корне бакета.
- Убедитесь, что мета-теги отображаются корректно.
