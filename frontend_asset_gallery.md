# 🖼️ Инструкция: Галерея Ассетов (Frontend)

Я добавил новый API эндпоинт для реализации галереи, где пользователь может выбрать свои прошлые работы (**картинки** или кадры из видео) для создания новых роликов.

## 🔗 Эндпоинт
- **GET** `/api/v1/assets/all` - ВСЕ генерации (картинки, видео, аудио) для вкладки "История".
- **GET** `/api/v1/assets` - Для выбора кадра (картинки и видео с кадрами).

**Headers:** `Authorization: Bearer <token>`
**Query (для /assets):** `?type=video` или `?type=image`.

## 📦 Структура ответа
В массив `data` приходят объекты следующего вида:

```json
{
  "id": 123,
  "type": "video",
  "resultUrl": "https://.../video.mp4",
  "lastFrameUrl": "https://.../last_frame.jpg",
  "previewUrl": "https://.../last_frame.jpg", 
  "prompt": "Оригинальный промпт...",
  "createdAt": "2026-02-11T..."
}
```

### Ключевые поля для галереи:
1.  **`previewUrl`**: Идеально подходит для `<img src={...} />` в списке выбора.
    - Для картинок это сама картинка.
    - Для видео это автоматически извлеченный последний кадр.
2.  **`type`**: Используйте для иконок (видеокамера/картинка) в углу превью.

## 🔄 Логика переиспользования (Re-use)
Когда пользователь выбирает ассет из галереи для создания нового видео из картинки (**Image-to-Video**):

1.  Возьмите значение из поля **`previewUrl`** (или `lastFrameUrl`).
2.  Подставьте его в поле **`image_url`** при вызове `POST /api/v1/videos/generate`.

### Пример запроса на генерацию с использованием кадра:
```json
{
  "prompt": "Теперь человек превращается в птицу",
  "model": "veo3_fast",
  "image_url": "URL_ИЗ_PREVIEW_В_ГАЛЕРЕЕ"
}
```

---
## 🎼 Обработка Аудио (Music/SFX)
В эндпоинте `/api/v1/assets/all` приходят и аудио-файлы.
- **`type`**: `"audio"`
- **`resultUrl`**: Прямая ссылка на `.mp3` или `.wav`.
- **`previewUrl`**: Будет `null`. Фронтенду рекомендуется использовать стандартную иконку аудио или плеер.
